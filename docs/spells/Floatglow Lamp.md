# Floatglow Lamp

Floatglow lamp is a light-type spell invented by Olruggio that makes objects float and glow.

## Description
Floatglow lamp consists of a central light sigil surrounded by alternating float and column signs. The spell causes the object it is drawn on to float and glow, and was invented by Olruggio for use in his contraption, the glowstone path, which glows whenever stepped on.
