# Sylph Shoes Seal

The sylph shoes seal is a wind-type spell that allows the user of items using it to fly.

## Description
The sylph shoes seal contains a central wind underfoot sigil (a variant of the wind sigil) surrounded by an alternating pattern of convergence and levitation keystones. So far, it has only been seen on sylph shoes, contraptions which allow the user to float above the ground whenever the two shoes are touched together. The glyph is bisected into two portions, on half on each shoe, and when the shoes touched together, the glyph is completed and activates, allowing the user to fly.

## Usage
So far, every appearance of the sylph shoes seal has coincided with an appearance of the sylph shoes themselves, as they are the glyph that allows the shoes to function. They have been seen used by Qifrey, Agott, Coco, Richeh, Tetia, and the Knights Moralis.
