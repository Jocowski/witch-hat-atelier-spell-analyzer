# Pyreball Seal

Pyreball seal is a fire-type spell used to create a levitating ball of flame.

## Description
Pyreball seal is a spell that contains a central fire sigil with levitation keystones arranged around it. This spell produces a ball of fire that will levitate both itself and any object that isn't too heavy directly above the glyph.

## Usage
This spell was used during chapter 8 by Coco under the instruction of Qifrey to cook carapace yams for a picnic.
