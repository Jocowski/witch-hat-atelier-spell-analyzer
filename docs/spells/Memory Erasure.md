# Memory Erasure

Memory Erasure is a type of spell, mostly used by the Knights Moralis to wipe the knowledge of forbidden magic from it's perpetrators.

## Description
Several variants of the spell are seen, though all are incredibly similar, with only minor additions such as an additional keystone setting them apart. The sigil at the center is made of concentric circles with a dot in the middle. Several hand-like keystones stem from it, and the circle also contains dot-shaped keystones. Unlike most glyphs, the memory erasure spells seen are all white on a black background, instead of drawn with ink on a surface.

As far as the effects of the different variants, four different kind of memory erasure spells are known. The first, used on Qifrey when he was young, totally wipes the mind of the one it is used on. The second wipes all memory of magic, and is the kind employed by the Knights Moralis most frequently. The third wipes all memory of a secret or conversation, used by Qifrey and potentially Mr. Nolnoa, and the last wipes all memory of a person, mentioned by Tartah when he and Coco were discussing what would happen of the knights learned Coustas was a brimmed cap.

During the River Rescue Arc, the spell can be seen growing short protrusions and reaching for Coco’s face, almost as if it was alive.

## Usage
Memory erasure spells are the only type of magic allowed to be used on the body. They are not qualified as forbidden magic, and are mostly used by the Knights Moralis. It is highly likely that the Knights are the only people permitted to use the spell, which they utilize wipe the memory of the witches they catch practicing forbidden or illegal magic, or who have commit serious crimes[2].

When Qifrey was found by Beldaruit, together with some Knights Moralis, after having been a victim of the Brimmed Caps, it was quickly revealed that the Brimcaps had wiped his memory, having used this spell on him.[3] Unlike the more selective memory erasure practiced by the Pointed Hat Witches, the instances where Qifrey casts memory erasure spells only rid their victims of the memory of a specific event. When the magic of the Knights is mentioned, it's to "wipe the memories of magic" and not a plain memory wipe, which might imply the magic has precision to a degree.

How it works, however, is currently unknown. The boy had his mind entirely wiped, and lacked some basic knowledge as a result.

Ironically, Qifrey has also used memory erasure spells himself, specifically on Olruggio. While it is implied he had done so several times prior, the spell we see him using was similar to the one Easthies uses in chapter 11, and hidden under the flap of his cap. The variant Qifrey had used specifically wipes all memories within a specific time frame, going from an unspecified time before the spell was used to the moment it was activated. Qifrey had also used a memory erasure spell on Mr. Nolnoa to avoid him contacting the authorities after discovering the properties of Iguin's ink pot.
