# Light Tracer

Light Tracer is the spell of the Crystal Fragment Bangles created by Richeh as her Contraption for Silver Eve.

## Description
Having the same basis of the Boulder Stretch Rope, but with a light sigil replacing the earth one and with a extra keystone at the top with an unknown effect, but it is assumed to make the connection between the rings. If an item is broken apart and a light tracer glyph is drawn on one of it's fragments, the spell will send a string of light to all other fragments of that object, this effect being visible in the crystal fragment bangles.
