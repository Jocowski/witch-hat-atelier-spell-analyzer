# Billowing Collection

Billowing collection is a niche spell that creates a cloud out of any material that is directed into it.

## Description
Billowing collection contains a central billowing sigil surrounded by collection signs. It collects material directed into it and converts said material into a cloud.

## Usage
The billowing collection glyph was used in the serpent's bed of sand glyph, where it served to convert the sand generated by the other parts of the spell into a cloud upon which the dragon hunting the girls slept, allowing them the time to destroy the illusory labyrinth glyph which was preventing their escape.
