# assets/spells

Reproduction assets for documented spells: user-provided **screenshots/PNGs** of a
seal and the app's **JSON export** (`wha-spell@1`), so any documented spell can be
re-created later by importing the JSON into the Spell Analyzer app or by redrawing
from the image.

Naming: match the doc file, `Title_Case_With_Underscores.{png,json}`
(e.g. `Watershot_Seal.png`, `Watershot_Seal.json`).

> Distinct from [../images/spells/](../images/spells/), which holds the source-material
> reference art used by the docs. This folder holds reproductions of analyzed/created
> spells.

The **/spell-analyzer** skill asks the user for these after writing a spell's doc.
